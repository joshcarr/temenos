# The library

Everything the Plate says when there's no network, written for this app. Edit any file by hand; the app reads the headings.

```
figures/<id>.md   one per figure: frontmatter (epithets, colour, voice affinity), then
                  Core, Gift, Shadow, Jungian echo, Myths, Images, Readings,
                  Figure prompts (by lens), Wild cards
anchors/dawn.md   the seven morning families, re-cut per figure
anchors/dusk.md   the seven evening families, re-cut per figure
myths/<id>.md     300–500 word retellings (to come), culture of origin in frontmatter
voices/<id>.md    persona sheets (to come)
```

Conventions:
- A prompt tagged `[imaginal]`, `[synchronicity]` or `[trickster]` is only used under that lens. Untagged means any lens.
- A reading heading is `### <voice> · <lens>`.
- Myths are listed as `- <id>: <one line> (<culture>)`; the id names the retelling file.
- Wild cards are drawn once and never repeat, so the pools need to keep growing.

Rules for every line: no predictions, no telling you who you are or what to do, no flattery, nothing quoted from copyrighted work. Dusk prompts ask for images, figures, feelings or patterns, not a recap.
